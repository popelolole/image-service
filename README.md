# Image Service

Image service for the
[Healthcare Microservices Platform](https://github.com/popelolole/healthcare-microservices-platform).

Handles image uploads, retrieval and updates. Data is stored in MongoDB and
access is integrated with Keycloak.

## Tech

TypeScript · NestJS · MongoDB · Keycloak · Docker · Kubernetes

## CI/CD

GitHub Actions runs the tests and builds and publishes a Docker image.
